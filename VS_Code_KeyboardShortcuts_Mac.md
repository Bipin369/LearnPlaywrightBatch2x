# VS Code Keyboard Shortcuts - macOS

Here are some of the most common keyboard shortcuts for Visual Studio Code (VS Code) on macOS. These are based on the default keybindings. Note that shortcuts can be customized, and some may vary based on your keyboard layout or extensions.

## General Shortcuts
| Action | Shortcut |
|--------|----------|
| Command Palette | Cmd + Shift + P |
| Quick Open (files) | Cmd + P |
| New Window | Cmd + Shift + N |
| Close Window | Cmd + Shift + W |
| User Settings | Cmd + , |
| Keyboard Shortcuts | Cmd + K Cmd + S |
| Extensions | Cmd + Shift + X |

## View/Navigation
| Action | Shortcut |
|--------|----------|
| Toggle Sidebar | Cmd + B |
| Show Explorer | Cmd + Shift + E |
| Show Search | Cmd + Shift + F |
| Show Source Control | Cmd + Shift + G |
| Show Debug | Cmd + Shift + D |
| Show Problems | Cmd + Shift + M |
| Show Output | Cmd + Shift + U |
| Show Debug Console | Cmd + Shift + Y |
| Toggle Terminal | Cmd + ` |
| Create New Terminal | Cmd + Shift + ` |

## Debugging
| Action | Shortcut |
|--------|----------|
| Start/Continue | F5 |
| Step Over | F10 |
| Step Into | F11 |
| Step Out | Shift + F11 |
| Stop | Shift + F5 |
| Restart | Cmd + Shift + F5 |

For a complete printable reference, visit: [macOS shortcuts PDF](https://go.microsoft.com/fwlink/?linkid=832143)

To customize shortcuts, open the Keyboard Shortcuts editor with Cmd+K Cmd+S.
