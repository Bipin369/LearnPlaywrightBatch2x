## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Bipin369/LearnPlaywrightBatch2x.git
   cd LearnPlaywrightBatch2x
   ```

2. Install dependencies (if any):
   ```bash
   npm install
   ```

3. Run any JavaScript file:
   ```bash
   node Chapter_01_Basics/01_Basics.js
   ```
